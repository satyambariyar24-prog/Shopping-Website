# Introduction

This project is a responsive shopping website developed using HTML, CSS, and JavaScript. The website provides a user-friendly interface where users can browse products, add items to a shopping cart, manage quantities, and view the total price.

The project focuses on building practical frontend functionality using JavaScript DOM manipulation, event handling, and browser storage.

🛠️ Technologies Used
HTML5 – Website structure
CSS3 – Styling and responsive design
JavaScript (ES6+) – Application logic and interactivity
LocalStorage – Persistent shopping cart data
✨ Features
🛍️ Product listing
🔎 Product browsing
🛒 Add products to cart
➕ Increase product quantity
➖ Decrease product quantity
❌ Remove products from cart
💰 Automatic total price calculation
💾 Cart data stored using LocalStorage
📱 Responsive design
🎯 Project Objectives
Build a functional shopping website using frontend technologies
Practice JavaScript DOM manipulation
Implement shopping cart functionality
Understand event handling in JavaScript
Work with LocalStorage
Create a responsive user interface
